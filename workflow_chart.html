Video Ingestion & Buffer
core/video_source.py
  • Supports dual inputs: Live USB Webcam (Device ID 0) or local video files (MP4, AVI, MKV, MOV).
  • Abstracts OpenCV cv2.VideoCapture stream reading.
  • Maintains frame loop state, total frame counts, and seek positions.
  • Driven by high-precision PyQt5 QTimer synchronized to video native FPS rate.

Lucas-Kanade Tracker
core/lucas_kanade.py
  • Detects sharp corner features using Shi-Tomasi criteria (cv2.goodFeaturesToTrack).
  • Tracks feature displacements frame-to-frame with Pyramidal LK optical flow.
  • Maintains a rolling trajectory queue of up to 25 motion trail points per feature.
  • Automatic feature re-detection when tracked point count falls below minimum threshold (30 points).

Farnebäck Dense Flow
core/farneback.py
  • Computes two-dimensional velocity vector matrix (h, w, 2) for every image pixel.
  • Transforms cartesian vectors (dx, dy) into polar coordinates (Magnitude, Angle).
  • Encodes direction into HSV Hue channel, and speed magnitude into Value/Brightness channel.
  • Renders crisp vector arrow overlay at configurable pixel grid steps (default 16px).
calcOpticalFlowFarneback cartToPolar HSV Color Map
Motion Heatmap Accumulator
core/motion_heatmap.py
  • Calculates frame difference intensity with Gaussian noise reduction.
  • Applies temporal exponential decay formula: Acc = Acc × decay + diff.
  • Normalizes cumulative heat intensities into 8-bit image ranges.
  • Maps heat intensities to false-color spectrums (INFERNO, JET, HOT, TURBO, VIRIDIS).

MOG2 Object Tracker
core/motion_detector.py
  • Uses Gaussian Mixture Model (MOG2) for dynamic background subtraction and shadow suppression.
  • Applies morphological Opening, Closing, and Dilation to filter noise and join fragments.
  • Finds object contours, bounding boxes, area metrics, and centroid coordinates.
  • Calculates velocity vectors, movement speed (px/frame), and 8-cardinal directional arrows (↗, ↑, ↘).

Analytics & PyQt5 Interface
gui/ & core/motion_stats.py
  • Calculates live metrics: Average speed, max magnitude, active motion coverage %, total points.
  • Computes 8-octant polar direction histogram showing distribution of optical flow angles.
  • Converts OpenCV BGR image matrix to Qt QImage / QPixmap for smooth GPU-accelerated rendering.
  • Real-time PyQt signal-slot binding connects parameter sliders directly to optical flow parameters.
